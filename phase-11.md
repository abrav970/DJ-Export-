# PHASE 11 — GLOBAL NAVIGATION AND TRANSITIONS

Now refine the global experience without changing the content.

## Navigation

Create a navigation state system:

Initial:

* transparent/minimal over hero

Scrolled:

* subtle background
* controlled blur if appropriate
* thin border
* maintained readability

Do not use excessive glassmorphism.

## Scroll progress

Implement a subtle global scroll progress indicator.

It should communicate the user's position within the overall story.

Do not make it visually dominant.

## Section transitions

Review every boundary:

Hero → Wayanad
Wayanad → Pepper
Pepper → Coffee
Coffee → Cardamom
Products → Quality
Quality → Export
Export → Global
Global → CTA

There should be no abrupt visual jumps.

The homepage should feel like one continuous experience.

## Important

Do not add more animation simply because a section is static.

Only add motion where it improves continuity, hierarchy or storytelling.
